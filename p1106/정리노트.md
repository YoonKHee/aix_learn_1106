## 오늘 배운 것
- 머신러닝 기본 흐름: **fit(학습) → predict(예측) → score(평가)**
- XOR 데이터로 SVM 맛보기 (`p1106_01.py`)
- iris(붓꽃) 데이터로 품종 분류 (`p1106_03.ipynb`)
- 학습/테스트 데이터 **8:2 분리**

## 핵심 개념
| 용어 | 뜻 |
|---|---|
| 지도학습 | 문제(data)와 정답(label)을 같이 주고 학습 |
| 분류 | 정해진 종류 중 하나 고르기 (품종, 도미/빙어) |
| 특성(feature) | 문제, 입력값 (꽃잎·꽃받침 길이 등) |
| 정답(label) | 맞혀야 하는 값 (품종) |
| 학습/테스트 분리 | 100문제 중 80개로 공부, 20개로 시험. 시험 문제는 공부할 때 숨김 |
| SVM (`svm.SVC`) | 두 무리 사이에 **가장 넓은 길(경계선)**을 그어 나눔. 애매한 몇 개는 틀려도 감수(소프트 마진) |

## 코드 패턴
```python
from sklearn import svm, metrics
from sklearn.model_selection import train_test_split

df = pd.read_csv('data/iris.csv', index_col='caseno')

# 1. 글자 정답 → 숫자 (한 번만 실행!)
df['Species'] = df['Species'].apply(nameChange)

# 2. 문제 / 정답 나누기
data  = df[['SepalLength','SepalWidth','PetalLength','PetalWidth']]
label = df['Species']

# 3. 8:2 분리 (순서: 학습문제, 테스트문제, 학습정답, 테스트정답)
train_data, test_data, train_label, test_label = \
    train_test_split(data, label, test_size=0.2, stratify=label, random_state=0)

# 4. 학습 → 예측 → 평가
clf = svm.SVC()
clf.fit(train_data, train_label)
result = clf.predict(test_data)
print(clf.score(test_data, test_label))     # 1.0 = 100%
```

## 옵션 정리
- `test_size=0.2` : 20%를 테스트용으로
- `stratify=label` : 품종 비율을 학습/테스트에 똑같이 유지
- `random_state=숫자` : 섞는 순서를 고정 → 매번 같은 결과 (숫자 자체는 의미 없음, 42는 관습)

## 자주 한 실수
- `nameChange` 셀을 **두 번 실행** → 전부 2가 됨 → `class가 1개` 에러. `read_csv`부터 다시 실행
- `data`, `label` 만드는 셀이 주석 처리되어 있거나 **아래쪽**에 있음 → 셀은 위에서부터 순서대로
- `df.columns()` ❌ → `df.columns` (괄호 없음)
- `predict` 할 때 입력은 2차원: `clf.predict([[5.1, 3.5, 1.4, 0.2]])`
