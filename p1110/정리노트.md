# 11/10 정리노트 — 원핫인코딩, 회귀(KNN·선형·다항)

## 오늘 배운 것
- 정답을 `'도미'`, `'빙어'` 글자로 사용, `classification_report` (`p1110_01`)
- 버섯 데이터: 글자 → 숫자 `ord()` / **원핫인코딩** `get_dummies` (`p1110_02`)
- **회귀** 시작: KNN 회귀 → 선형회귀 → 다항회귀 (`p1110_03~08`)

## 분류 vs 회귀
| | 분류 | 회귀 |
|---|---|---|
| 예측하는 것 | 종류 (도미/빙어) | 숫자 (무게 245g) |
| 모델 예 | KNeighborsClassifier, SVC | KNeighborsRegressor, LinearRegression |
| score 뜻 | 정확도 | R² (1에 가까울수록 좋음) |

## 핵심 개념
| 용어 | 뜻 |
|---|---|
| 원핫인코딩 | 글자 종류마다 칸을 만들어 0/1로 표시. 크기 관계 오해를 막음 |
| `mean_absolute_error` | 예측이 실제와 **평균 몇 g** 차이 나는지 |
| `reshape(-1, 1)` | 줄 수는 알아서, **1칸**짜리 2차원으로 (특성이 1개일 때 필수) |
| `coef_`, `intercept_` | 기울기, 절편 → 무게 = 기울기 × 길이 + 절편 |
| 다항회귀 | `[길이², 길이]` 칸으로 **곡선** 학습 |

## 코드 패턴
```python
# 특성이 1개면 2차원으로
train_data = train_data.reshape(-1, 1)
test_data  = test_data.reshape(-1, 1)

# 선형회귀
lr = LinearRegression()
lr.fit(train_data, train_label)
lr.predict([[50]])
plt.plot([15, 50], [15*lr.coef_+lr.intercept_, 50*lr.coef_+lr.intercept_])   # 직선

# 다항회귀
train_poly = np.column_stack((train_data**2, train_data))   # 괄호 두 겹!
test_poly  = np.column_stack((test_data**2, test_data))
lr.fit(train_poly, train_label)
lr.predict([[50**2, 50]])                                   # 예측도 [길이², 길이]

point = np.arange(15, 50)                                   # 곡선 그릴 x값
plt.plot(point, lr.coef_[0]*point**2 + lr.coef_[1]*point + lr.intercept_)
```

## 자주 한 실수
- 버섯: `for v in row:` → 정답 칸까지 들어감. `row[1:]`로
- `iloc[0]` = 첫 **행**. 열은 `iloc[:, 0]`
- `random_state` 없으면 실행마다 오차·점수가 달라짐 (강사님과 다를 수 있음)
- `plt.plot([x1,x2], y1, y2)` ❌ → `plt.plot([x1,x2], [y1,y2])`
- 선형회귀는 짧은 길이에서 **음수** 무게 → 직선의 한계
- `print('리포트',/n,report)` ❌ → `print('리포트\n', report)`
