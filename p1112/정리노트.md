## 핵심 개념
| 용어 | 뜻 |
|---|---|
| LogisticRegression | 이름은 회귀지만 **분류** 모델. 확률(0~1)을 계산해서 종류를 정함 |
| 이진 분류 | 정답이 2종류 (도미/빙어, 스팸/정상) |
| 다중 분류 | 정답이 3종류 이상 (붓꽃 3종, 생선 7종) |
| `decision_function` | 종류별 **점수(z값)** |
| 시그모이드 `expit` | 이진 분류: z값 1개 → 확률 |
| 소프트맥스 `softmax` | 다중 분류: z값 여러 개 → **합이 1인 확률** |
| `predict_proba` | 위 계산을 알아서 해준 **최종 확률**. 실제로는 이것만 쓰면 됨 |
| `classes_` | 확률 칸의 종류 순서 (알파벳 순) |
| `C` | 규제 강도. **클수록 약함** (기본값 1). alpha와 반대 |
| `max_iter` | 최적값 찾을 때 최대 반복 횟수 |

## 흐름
```
특성 → decision_function(점수) → 시그모이드/소프트맥스 → 확률 = predict_proba → 가장 큰 쪽으로 predict
```

## 코드 패턴
```python
data  = fish.drop(columns=['Species']).values      # drop( ) 소괄호
label = fish['Species'].values
train_data, test_data, train_label, test_label = train_test_split(data, label, random_state=42)

ss = StandardScaler()                               # LogisticRegression, KNN은 정규화 필수
ss.fit(train_data)
train_scaled = ss.transform(train_data)
test_scaled  = ss.transform(test_data)

lr = LogisticRegression(C=20, max_iter=1000)
lr.fit(train_scaled, train_label)

# 입력받아 확률과 함께 출력
num   = list(map(float, input('데이터:').split(',')))
new   = ss.transform([num])                         # fit 하지 말 것!
pred  = lr.predict(new)[0]
proba = lr.predict_proba(new)[0].max()
print(f'분류생선 : {proba*100:.1f}%의 확률로 {pred} 판별됩니다.')

# 원리 확인용
softmax(lr.decision_function(test_scaled[:5]), axis=1)   # = predict_proba
```

## 실생활 이진 분류와 기준(확률) 조절
| 서비스 | 1의 뜻 | 기준 | 이유 |
|---|---|---|---|
| 스팸 필터 | 스팸 | 높게 (0.9) | 정상 메일을 버리면 안 됨 |
| 카드 사기 탐지 | 사기 | 낮게 (0.3) | 사기를 놓치면 손해 |
| 병 진단 | 위험 | 낮게 (0.3) | 환자를 놓치면 위험 |

## 자주 한 실수
- **입력값으로 `ss.fit`** → 정규화가 전부 0 → 무엇을 넣어도 같은 결과. 새 데이터는 `transform`만
- `p[0,:-1]`(배열)에 `:.2f` ❌ → `p[0].max()` (숫자 하나)
- `.max` → `.max()` 괄호
- `softmax(x),axis=1` ❌ → `softmax(x, axis=1)`
- `df.drop['Species']` ❌ → `df.drop(columns=['Species'])`
- Restart 후 import 셀을 안 돌리면 `NameError`
