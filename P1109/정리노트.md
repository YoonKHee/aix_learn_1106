## 핵심 개념
| 용어 | 뜻 |
|---|---|
| KNN (`KNeighborsClassifier`) | 새 데이터와 **가장 가까운 이웃 5개**의 투표로 분류 |
| 정규화 | 열마다 다른 숫자 크기를 비슷하게 맞추는 전처리 |
| 표준점수 | (값 − 평균) / 표준편차 → 대략 −2 ~ 2 |
| `axis=0` | **열(세로)** 기준 계산 → 길이 평균, 무게 평균 2개 |
| `kneighbors` | 가까운 이웃의 거리(`distances`)와 번호(`indexes`) |

**왜 정규화?** 길이(10~40)보다 무게(6~1000) 숫자가 커서 KNN이 무게만 보고 판단함.
→ 25cm·150g 생선이 정규화 전엔 **빙어**, 정규화 후엔 **도미**로 맞게 나옴.

## 코드 패턴
```python
# 도미+빙어 합치기
length = bream_length + smelt_length
weight = bream_weight + smelt_weight
data  = np.column_stack((length, weight))   # [길이, 무게] 49줄
label = [1]*35 + [0]*14                     # 도미 1, 빙어 0

train_data, test_data, train_label, test_label = train_test_split(data, label, stratify=label)

# 정규화: fit은 훈련 데이터로만!
ss = StandardScaler()
ss.fit(train_data)
train_scaled = ss.transform(train_data)
test_scaled  = ss.transform(test_data)
new_scaled   = ss.transform([[25, 150]])    # 새 데이터도 transform만

clf = KNeighborsClassifier()
clf.fit(train_scaled, train_label)          # 정규화한 값으로 학습
clf.predict(new_scaled)                     # 예측도 정규화한 값으로

distances, indexes = clf.kneighbors(new_scaled)
plt.scatter(train_scaled[indexes,0], train_scaled[indexes,1], marker='D')  # 이웃 표시
```

## 자주 한 실수
- `input()` 값은 **문자열** → `float()`로 바꿔야 그래프·예측 가능
- `[[test1]]` 처럼 괄호 3겹 → `[test1]` (2겹)
- `test_label = label_numpy[index[:35]]` → 테스트는 `index[35:]` (data와 label 짝 맞추기)
- `plt.xlabel = '길이'` ❌ → `plt.xlabel('길이')`. 덮어쓰면 Restart 필요
- 정규화한 데이터로 학습했는데 예측에 원래 값을 넣음 → 항상 도미로 나옴
